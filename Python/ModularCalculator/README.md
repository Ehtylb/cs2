Modular Calculator

A simple Python modular calculator created for Quarter 2 Part 3.

Version 1

Version 1 is the initial working version of the calculator. It uses separate functions for:

* Addition
* Subtraction
* Multiplication
* Division

The program accepts two numbers and allows the user to choose an arithmetic operation.

Features

* Uses functions with parameters
* Uses arguments when calling functions
* Uses return values
* Handles division by zero
* Displays the calculation result clearly
